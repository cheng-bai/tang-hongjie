# Local font subsets

Noto Serif SC, DM Sans, and DM Mono, obtained from Google Fonts on 2026-10-26. Font files are text subsets for this page and are self-hosted; there are no runtime requests to Google. Licenses are preserved in the accompanying OFL files. If adding new Chinese text, extend the subset or use the declared platform serif fallback.

Sources: https://fonts.google.com/ and https://github.com/google/fonts/tree/main/ofl
