# 唐宏杰 · 教学现场 × AI 教育

个人主页，展示高中数学教学、学科研发与 AI 教育应用实践。

## 本地预览

无需安装依赖或构建。使用 Python 3 在此目录运行：

```sh
python3 -m http.server 8766 --bind 127.0.0.1
```

然后访问 `http://127.0.0.1:8766/`。也可以直接打开 `index.html`。

## 文件

- `index.html`：中文主页与 SVG / CSS 原创概念配图。
- `styles.css`：响应式视觉样式、减少动态效果适配。
- `script.js`：渐进增强的滚动呈现；禁用 JavaScript 不影响阅读与导航。
- `fonts/`：本地字体子集和开源许可证，不依赖 Google Fonts 的在线加载。

## 发布边界

只发布公开个人介绍，不包含院校及专业表述、学生资料、私人文档、原题、内部截图或本机路径。项目图片是概念示意，不是产品实拍。四个概念卡片后补充六项项目经历，使用原生 details 展示工作与阶段成果，禁用 JavaScript 也可展开。

各项目分别注明阶段：本机实践、历史部署、研究阶段本或开源发布，不暗示均已商业上线、能够自动学情诊断或具有经过验证的学习效果。历史部署不作为实时可用保证；规模数字保留来源日期。授课时长的统计截止时间明确为 2025 年 12 月。

此次更新仅提取适合公开的经历文字，不上传经历扩充稿、内部依据表、教材原文、收卷数据或内部研发报告。页面上的唯一外部作品入口为开源数学动画项目。

页面不包含统计、广告、追踪、表单或后端，不收集访客信息。

## 部署

GitHub Pages，使用 `codex/personal-homepage` 分支根目录，无构建步骤。更新网页文件后推送到该独立仓库即可触发重新发布。

外部文档查询：2026-10-26 通过 Context7 查询 GitHub Pages REST API 官方文档（`https://docs.github.com/en/rest/pages/pages`），采用分支根目录发布，`source.path=/`。不购买域名、不启用付费服务。
