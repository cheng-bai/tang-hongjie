# 承白 / chengbai · 教学现场 × 旗舰作品集

个人主页与公开简历，展示高中数学教学、学科研发与 AI 教育应用实践。

## 线上地址

- 主页：`https://cheng-bai.github.io/tang-hongjie/`
- 公开简历：`https://cheng-bai.github.io/tang-hongjie/resume.html`

## 本地预览

无需安装依赖或构建。使用 Python 3 在此目录运行：

```sh
python3 -m http.server 8766 --bind 127.0.0.1
```

然后访问 `http://127.0.0.1:8766/`。也可以直接打开 `index.html`。

## 文件

- `index.html`：中文主页、简历入口与旗舰作品集。
- `resume.html`：公开简历，可直接打印或保存为 A4 PDF。
- `resume.css`：简历的屏幕阅读与打印样式，独立于主页样式。
- `styles.css`：响应式视觉样式、减少动态效果适配。
- `script.js`：渐进增强的滚动呈现；禁用 JavaScript 不影响阅读与导航。
- `fonts/`：本地字体子集和开源许可证，不依赖 Google Fonts 的在线加载。
